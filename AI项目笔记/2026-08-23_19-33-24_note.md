# 自动导出项目汇总 HTML

## 本次完成
新增批量导出脚本，可自动发现 `AI项目汇总/` 下的项目总结并生成便于浏览和分享的独立 HTML 文件，同时补充使用说明与回归测试。

## 关键改动
- `scripts/export_summaries.py`：使用 Python 标准库解析当前汇总使用的 Markdown 结构，移除 frontmatter 和内部注释，安全生成带基础样式的 HTML。
- `tests/test_export_summaries.py`：验证格式转换、危险原始 HTML 转义、元数据隐藏和重复导出的确定性。
- `README.md`：补充 HTML 导出命令和输出目录。
- `.gitignore`：忽略 Python 缓存文件。
- `HTML汇总/`：生成现有三个项目的 HTML 汇总。

## 验证结果
- `python3 -m py_compile scripts/export_summaries.py tests/test_export_summaries.py`：通过。
- `python3 -m unittest -v tests.test_export_summaries`：1 项测试通过。
- `python3 scripts/export_summaries.py`：成功生成 3 个 HTML 文件，重复执行结果稳定。
- `html.parser` 产物检查：三个文件均可解析、各含一个一级标题，且未泄露 frontmatter 与内部来源注释。
- `git diff --check`：通过。

## 值得学习
- 针对格式固定的内部 Markdown，支持实际使用的语法子集比引入完整转换依赖更便于跨设备运行；同时必须先转义原始 HTML，避免把笔记内容变成可执行代码。

## 决策与取舍
- 使用 Python 标准库实现当前汇总需要的标题、段落、列表、代码、强调、链接和引用转换；未引入第三方 Markdown 包，也未实现当前内容未使用的复杂表格和嵌套列表。

## 后续事项
- 汇总内容更新后重新运行 `python3 scripts/export_summaries.py` 即可刷新 HTML；若未来使用复杂 Markdown，再扩展对应语法。
