# 全局规划切换为 SmacPlanner2D

## 本次完成
将全局规划器从 Smac State Lattice 切换为 Humble 的 `SmacPlanner2D`，移除运动 primitive 和 Lattice 专属参数，使全局路径改用二维栅格 A* 搜索。

## 关键改动
- `src/bxi_nav/config/nav2_smac_mppi_params.yaml`：配置 `nav2_smac_planner/SmacPlanner2D`、栅格代价权重和终点朝向行为。
- `src/bxi_nav/launch/navigation_direct_cmd_vel_launch.py`：删除 lattice 文件路径动态重写。
- `src/bxi_nav/CMakeLists.txt`：删除 Nav2 diff-drive primitive 的定位、校验和安装逻辑。
- `src/bxi_nav/test/test_nav2_planning_contract.py`：以 SmacPlanner2D 参数和无 lattice 依赖为新契约。

## 验证结果
- SmacPlanner2D/行为树/Rotation Shim 定向 pytest：4 passed，25 deselected。
- launch Python 语法检查：通过。
- `colcon build --packages-select nav --symlink-install`：成功。
- 安装空间检查：使用 `SmacPlanner2D`，不再引用 lattice；遗留 primitive 已删除。
- 完整 Python 契约：23 passed，3 skipped，3 个当前控制器/局部膨胀参数与旧测试期望不一致的失败。

## 值得学习
- SmacPlanner2D 使用二维栅格搜索，不需要运动 primitive；Lattice 专属搜索参数必须一并删除，否则会留下无效配置和部署依赖。

## 决策与取舍
- 保留行为树中的 `planner_id: SmacPlanner`，只替换其插件实现，避免修改 BT 接口；Rotation Shim 和 MPPI 继续负责机器人朝向与局部运动控制。

## 后续事项
