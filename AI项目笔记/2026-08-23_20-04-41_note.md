# 增加项目级 Skill 部署器

## 本次完成
将 `obsidian-project-note` 的可维护源码纳入笔记仓库，并新增零依赖部署脚本，可快速安装到另一个项目的 `.codex/skills/`。

## 关键改动
- `skills/obsidian-project-note/`：加入 Skill 指令、界面元数据及保存与汇总脚本源码。
- `scripts/deploy_obsidian_skill.py`：验证目标项目和 Obsidian 仓库、改写安装路径、原子部署 Skill，并在强制更新时保留旧版本备份。
- `tests/test_deploy_obsidian_skill.py`：覆盖首次安装、默认拒绝覆盖、路径改写及强制更新备份。
- `README.md`：补充项目级部署命令及与新设备迁移包的用途区别。

## 验证结果
- `quick_validate.py skills/obsidian-project-note`：Skill 结构与 frontmatter 通过。
- `python3 -m py_compile`：部署脚本、测试和 Skill 脚本语法通过。
- `python3 -m unittest discover -s tests -v`：2 项测试通过。
- 隔离项目 CLI 冒烟测试：Skill 安装成功，目标路径和笔记库路径改写正确，部署后再次通过 Skill 校验。
- `git diff --check`：通过。

## 值得学习
- 项目级 Skill 应安装到目标项目的 `.codex/skills/`；备份若留在该扫描目录中可能被误识别为重复 Skill，因此应放到独立的 `.codex/skill-backups/`。

## 决策与取舍
- 复用 Python 标准库完成复制、校验和安全替换，不引入依赖；新设备的 systemd 定时器仍由现有便携迁移包负责。
