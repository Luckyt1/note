本次完成

在现有相册 WebServer 上增加带认证的 Web OTA，使设备在首次通过 USB 安装双 OTA 分区后，可以从浏览器上传主程序固件并自动重启。

关键改动

  • Arduino/examples/LVGL_Arduino/LVGL_Arduino.ino：新增 /firmware 页面、BIN 上传校验、备用 OTA 槽写入、错误处理与成功重启，并复用现有 Digest 登录。
  • Arduino/examples/LVGL_Arduino/partitions.csv：新增适用于 16 MB Flash 的 ota_0、ota_1 双应用槽。
  • Arduino/examples/LVGL_Arduino/DISPLAY_SETUP.md：补充首次 USB 切换 Custom 分区及后续网页升级步骤。

验证结果

  • arduino-cli compile（ESP32-S3、16 MB、Custom 分区）：编译成功，固件 1,276,176 字节。
  • gen_esp32part.py：确认生成的分区表包含两个 6,553,600 字节 OTA 槽。
  • esptool.py image_info：确认输出是 ESP32-S3 镜像，Checksum 和 Validation Hash 均有效。

值得学习

  • ESP32 OTA 需要至少两个应用分区；只有单个应用槽的 Huge APP 分区无法安全写入下一版程序。
  • Web OTA 应先返回 HTTP 成功结果再重启，否则浏览器可能误报上传失败。

决策与取舍

  • 复用已有 WebServer 和六位 PIN Digest 认证，不增加 OTA 库依赖或第二个服务端口；暂不加入公网升级与自动回滚确认机制。

后续事项

  • 首次必须用 USB 选择 16 MB Flash 和 Custom 分区完整烧录；实际设备上的网页上传与重启仍需进行硬件实测。

为烧录脚本增加串口临时授权

烧录脚本增加 Linux 串口权限修复选项，可在用户确认后通过 sudo 临时授予串口读写权限，并继续执行硬件检测和烧录。
