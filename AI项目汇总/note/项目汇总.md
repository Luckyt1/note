### 本次完成
实现可定时执行的 Git 报告脚本：每天快进拉取并生成日报，每周四汇总周五至周四的日报，且仅在周报成功写入后删除源日报；随后自动提交报告、变基合并远端更新并推送回云端。

### 关键改动
- `scripts/git_reports.py`：增加安全拉取、提交统计、日报生成、周四周报、成功后清理，以及报告专属提交和云端同步逻辑。

- `README.md`：补充手动运行、补跑参数和 cron 配置示例。

### 验证结果
- `python3 -m unittest -v tests.test_git_reports tests.test_export_summaries tests.test_deploy_obsidian_skill`：3 项测试全部通过。
- `python3 -m py_compile scripts/git_reports.py tests/test_git_reports.py`：语法检查通过。
- `git diff --check`：未发现空白字符错误。

### 值得学习
- 对“生成后删除”流程，应先原子持久化汇总产物，再逐一删除源文件，避免写入失败造成数据丢失。
- 定时任务生成前使用 `git pull --ff-only`，提交报告后再使用 `git pull --rebase`，可以吸收并行出现的远端提交而不制造合并提交。

- `tests/test_daily_git_sync.py`：覆盖双仓库并发更新、自动 rebase/push、凭据拒绝、暂存状态恢复和 20:00 持久化定时器。

### 验证结果
- `python3 -m unittest discover -s tests -v`：6 项测试通过。
- `systemd-analyze verify`：新增 service 与 timer 无自身配置错误。
- `systemctl --user`：timer 为 enabled/active，下一次触发为 `2026-08-24 20:00:00 CST`，`Persistent=yes`。
