## 修复 ROS2 构建与 RGB 启动崩溃

### 本次完成
修复独立仓库模式下的 ROS2 构建路径错误，并修复 Odin 实际发送 JPEG、帧元数据却标记为 NV12 时触发的 OpenCV 越界段错误；驱动现在可持续启动并发布 RGB 图像。

### 关键改动
- `script/build_ros2.sh`：正确识别工作空间根目录，拒绝 sudo 构建并返回 colcon 退出码。
- `.gitignore`：忽略仓库内 ROS2 构建产物。
- `include/host_sdk_sample.h`：按 JPEG 负载签名识别格式，NV12 解码前校验指针、尺寸和缓冲长度，并在解码前复制 SDK 缓冲。

### 验证结果
- `colcon build --packages-select odin_ros_driver --cmake-args -DBUILD_SYSTEM=ROS2`：构建成功。
- `ros2 launch odin_ros_driver odin1_ros2.launch.py`：真实设备运行 30 秒，无 SIGSEGV 或 code 139。
- `ros2 topic echo --once /odin1/image --field header`：成功收到 RGB 图像消息。
- `bash -n script/build_ros2.sh && git diff --check`：检查通过。
