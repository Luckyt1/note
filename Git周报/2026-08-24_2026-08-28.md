# 2026-08-24 至 2026-08-28 周报

## 本周概览

本周工作围绕机器人导航稳定性、ELF3 三维仿真与模式编排工具展开，同时完善了圆屏设备运维和 AI 项目笔记自动化。已提交记录共 8 次，涉及 41 个文件，累计新增 5,407 行、删除 1,773 行；8 月 28 日尚未提交的项目汇总也纳入本周成果，但不计入上述 Git 统计。

## 重点成果

### 1. 收敛 ELF3 的 Nav2 导航链路

- 修复后方目标无法触发原地转向、TF 延迟导致 Rotation Shim 永久回退、短路径零速度卡死等问题。
- 为双足步态补充最低有效原地旋转速度，并围绕角加速度、旋转死区、路径重规划与规划器选择进行了多轮验证和收敛。
- 最终采用 SmacPlanner2D 与 MPPI 的前进导航方案，移除周期性全局重规划，保留全局动态障碍层和 6×6 米局部代价地图。
- 修复移除停车层后的速度话题断路、Point-LIO 缺少 glog 头文件、全局障碍观测不稳定及局部代价地图偶发不显示等集成问题。

### 2. 打通 3D 导航仿真和一键运行

- 为 `3D-nav-dev` 增加一键仿真启停与三维导航入口，补齐构建依赖，恢复实时日志和 RViz 点云显示。
- 将 RTAB-Map 切换为 MuJoCo 原生头部 RGB-D 相机，统一彩色与深度流为 640×360、30 Hz，并完成逐像素内参对齐。
- 通过 `COLCON_IGNORE` 消除嵌套工作区的重复包发现错误；修复 PCL/VTK 在 CMake 3.28 下缺少 `MPI::MPI_C` 的配置失败。
- 统一直接 Launch 与脚本启动时的 MuJoCo 场景、ROS 环境及 Fast DDS large-data profile，使 MuJoCo、ELF3 策略和 RTAB-Map 可由 `start.sh` 一键拉起。
- 生成可复现、可交互的中文运行时架构图，覆盖核心调用链、地图持久化、体素缓存和外部依赖。

### 3. 建设 ELF3 动作与模式编排能力

- 将 NPZ 和手写挥手轨迹接入 SONIC，完善持续挥手、右手挥手及双手抱头比心动作，并解决动作与遥控器入口冲突。
- 在 `bxi_rc_ros2` 实现零依赖网页模式搭建器，可保留基础安全模式、添加自定义模式、导入模型并导出带校验脚本的项目归档；同时修复跨目录启动时的 404。
- 在 `bxi_controller_ros2` 将网页工具收敛为直接管理 `bxi_example_py_elf3` 包内 Mods，支持目录导入、新增/删除 Mod、基础状态可逆编排和按键释放。
- 动态读取基础 Mod 的 state/event/route/action 清单，展示 Xbox、CRSF 与键盘映射；跳舞模式采用渐进披露表单和安全默认值，降低首次配置成本。
- 增加无额外依赖的一键启动脚本，并用真实包清单、代码生成一致性及 Node 测试覆盖主要导入导出流程。

### 4. 完善设备交付和维护入口

- 优化 ESP32-S3 圆屏完整固件烧录流程，将固件与脚本移到项目根目录，增加串口编号选择、临时授权、环境预检和面向新用户的快速开始说明。
- 为 LVGL 圆屏增加终端交互式远程固件升级入口，降低设备现场更新成本。
- 将室内仿真中的动态物体固定为静止物体，为导航验证提供更稳定的基准场景。

### 5. 完善项目知识沉淀

- 增加 Git 日报、周报生成与每日自动同步能力，使笔记进展能够定期提交并回传远端。
- 为 HTML 项目汇总增加日期导航并优化站点样式，方便按时间和项目回看工作记录。
- 精简项目汇总结构，统一移除低价值重复章节，并继续同步 Markdown 与 GitHub Pages 页面。
